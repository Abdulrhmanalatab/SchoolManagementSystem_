# School Management System

The School Management System is a web application designed to facilitate school management by providing an easy-to-use interface for administrators, teachers, students, and parents. The system allows for the management of information related to students, teachers, classes, and grades.

## Requirements

Before you begin, ensure you have the following requirements:

- A web server (such as Apache or Nginx)
- PHP (version 7.0 or higher)
- MySQL (version 5.6 or higher)
- phpMyAdmin (for database management)

## Installation

1. Download the project from the repository.
2. Extract the files to your local server directory.
3. Create a new database in MySQL and name it school_management.
4. Import the SQL file for the database (you can create it based on the structure mentioned).
5. Modify the db/db_connection.php file to set up your database connection.
6. Open your browser and go to http://localhost/school_management_system/index.php to start using the system.


## Features

- Secure login for users (Admin, Teacher, Student, Parent).
- Manage information about students, teachers, classes, and grades.
- View grades and schedules for students and parents.
- Simple and user-friendly interface.
